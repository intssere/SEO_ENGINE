# SEO ENGINE

AI-native SEO + AIO/GEO optimization platform.

SEO ENGINE is designed around a closed operating loop:

**Connect → Understand → Find → Decide → Act → Verify → Measure → Learn**

## Status

Architecture phase.

- Repository baseline: initialized
- Architecture lock: `docs/SEO_ENGINE_ARCHITECTURE_LOCK_V1.md`
- Public-site autonomous writes: **disabled until the Safety Engine, approval model, verification, and rollback controls are implemented**

## Initial Pilot

The first production pilot will target a Shopify ecommerce site and validate the full evidence-to-action loop before broader platform support is added.

## Engineering Principle

Commodity capabilities such as SERP data, generic SEO research, browser automation, and analytics ingestion should be integrated from mature tools and official APIs where appropriate. SEO ENGINE's proprietary focus is prioritization, safe execution, verification, experimentation, search-policy adaptation, and learning.
