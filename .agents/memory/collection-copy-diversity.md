name: Collection copy diversity
description: Deterministic generation and final-gate rules for structurally distinct collection metadata.
---

Collection-composition descriptions may vary only through deterministic phrasing around certified page identity and exact collection category evidence. The final quality gate must compare composition-generated collection proposals after replacing their evidence-bound identity and category phrases, so repeated sentence structures block promotion while ordinary required lexical overlap remains allowed.

**Why:** Exact collection evidence can support different category terms while a repeated sentence template still produces low-quality near-duplicate metadata. Treating shared evidence terms as duplication would also reject valid copy.

**How to apply:** Keep exact-value uniqueness and every evidence, membership, relevance, claims, stuffing, integrity, and boilerplate gate intact. Apply structural comparison only to proposals sourced from certified collection composition, and keep any structural match as a blocked dry run with all write and execution flags false.
