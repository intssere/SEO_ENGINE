# Incremental delivery plan and verification

## Phase 0 — repository discovery (no writes)
Inventory existing UGP/P12.2 models, routes, services, migrations, tests, adapters, schedulers, provider gates, documentation and production certification state. Produce source-linked traceability matrix and identify overlaps. No implementation until audit reviewed.

## Phase 1 — decision and evidence foundation
Implement necessity decision, site inventory alignment, evidence schema, claim lineage, contribution manifest and business truth checks. Unit tests + golden fixtures + adversarial cases. No provider mutation.

## Phase 2 — independent quality pipeline
Separate drafting and evaluation; editorial refinement with factual invariants; reader utility and risk gates; benchmark calibration against expert-labelled cases. Shadow-mode evaluation of existing articles.

## Phase 3 — governed publication integration
Reuse existing authorized execution infrastructure. Adapter capability negotiation, draft-only dry runs, idempotency, protected-field diff, readback, conflict and unknown-outcome reconciliation. Require explicit production authorization separately.

## Phase 4 — outcomes and portfolio intelligence
Connect consented metrics, baselines, experiments, refresh logic, cost budgets and decision calibration. Validate against simpler baseline rather than claiming success from internal scores.

## Per-increment definition of done
Code reviewed; tests and negative fixtures pass; migrations reversible; auth/tenant boundaries checked; no unexpected external effects; runbooks updated; architecture decisions logged; observed evidence linked; main/head SHA verified before merge. Production certification is a separate gate.

## Proposed tests
Claim contradiction, unsupported numeric claim, fake experience, source expiry, copyright restriction, duplicate intent, multilingual mismatch, YMYL missing review, prompt injection, tenant crossing, lost update, duplicate send, partial CMS write, canonical mismatch, noindex, provider timeout, stale authorization, rollback failure, metrics confounding.
